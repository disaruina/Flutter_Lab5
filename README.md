# Генератор цитат Джейсона Стетхема

Приложение представляет собой интерактивный сборник мемных цитат Джейсона Стетхема с картиноками. Оно переключает брутальные пацанские цитаты и соответствующие изображения по нажатию одной кнопки.

## Структура проекта
В папке `lib/` реализована чистая архитектура из трех отдельных файлов:
* `main.dart` - главная точка входа, запускает приложение и задает базовые цвета для фона.
* `background.dart` - кастомный статичный виджет (StatelessWidget), отвечающий за красивый градиентный фон.
* `generator.dart` - динамический виджет (StatefulWidget), содержащий списки картинок, цитат и всю логику циклического переключения по клику.

## Ответы на вопросы
1. **Зачем выносить виджеты в отдельные файлы?**
   Чтобы код не превращался в огромную кашу в одном файле. Это делает проект структурированным, улучшает читаемость и позволяет повторно использовать один и тот же виджет в разных частях программы.
2. **Что такое BuildContext? Почему метод build() принимает его как параметр?**
   BuildContext - это ссылка на положение конкретного виджета в общем дереве элементов. Метод build() принимает его, чтобы знать, где именно отрисовывать виджет и откуда брать глобальные данные (например, тему оформления).
3. **Чем StatelessWidget отличается от StatefulWidget? Приведите пример.**
   StatelessWidget - статичный, он создается один раз и сам не меняется (например, наш градиентный фон). StatefulWidget умеет хранить внутри себя изменяемое состояние и перерисовывать экран при его обновлении (как наш список цитат при клике).
4. **Почему Random() создаётся на уровне файла, а не внутри метода?**
   Если создавать объект генератора каждый раз внутри метода кнопки, это будет нагружать память лишней инициализацией при каждом клике. Объявление на уровне файла создает один объект, который оптимально используется повторно.
